# Page Pulse

Page Pulse is a Website Audit & SEO Analyzer built using Flask.

## Features

- Analyze any website URL
- HTTP Status
- Response Time
- Page Title
- Meta Description
- H1 Count
- Images Missing ALT
- Word Count

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- BeautifulSoup
- Requests

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Run

python app.py

3. Open

http://127.0.0.1:5000
